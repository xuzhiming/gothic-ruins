Use Blender 5.3.0 (02f0899d78e3), Python3, NumPy/Pillow (parameter docs), Node/npm. Install pinned offline glTF tools using `npm ci --prefix tools/gltf` if not already available; no package manager cache is included. Then:
```sh
BLENDER=/path/to/blender ./reproduce_assets.sh
```
No reference files are needed. The model itself is generated from source; baked original PNGs are reused. M13/15mm lime and all365 semantic window slots (360 true including original125 entirely missing ruin panes,5 opaque blinds) stay unchanged.

Private-reference IoU comparison and matched lighting-calibrated renders likewise remain local; only measured deltas and generated before/after model images are supplied.
