> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Architecture:** Pure layout module computes scaled widths, fixed datums, explicit side finish allowance, routes and guard extents. Blender consumes layout to build geometry and spaces. **Tech Stack:** Python 3, Blender Python, BVHTree, Cycles CPU, glTF Transform, NumPy/Pillow.
